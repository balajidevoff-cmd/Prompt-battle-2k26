GUIDELINES

Rules & Instructions

Read carefully before you participate. Follow the rules to compete fairly.

01

Prompt Only

Only the text prompt is evaluated. No post-processing, editing, or filters allowed on the generated output.

02

Allowed Tools

Use any publicly available AI tool (e.g., Midjourney, DALL·E, Stable Diffusion, Sora, Runway, Pika etc.).

03

Original Prompts

Prompts must be original. Copying from the internet or other participants is strictly prohibited.

04

Time Limit

Participants will be given a fixed time window to craft their prompt and submit the AI-generated output.

05

Submission Format

Image entries: JPG/PNG. Video entries: MP4/MOV, max 30 seconds. Submit via the official portal.

06

Judging Criteria

Scored on: Prompt Quality (40%), Visual Accuracy (30%), Creativity (20%), Technical Detail (10%).
